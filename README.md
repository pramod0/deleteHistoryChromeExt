**Delete History Chrome Extension**

**Overview**

Tired of manually clearing your browser history for certain websites? This Chrome extension automates the process by allowing users to configure sites whose history should be deleted. It also provides a manual cleanup button for instant action.

**Features**

✅ Stores websites that should have their history cleared
✅ Automatically deletes history for configured websites at intervals
✅ Clear History button for manual cleanup
✅ Selective deletion – only specified websites’ history is removed


**How It Works**

- Enter website URLs in the provided text field (e.g., example.com).
- The extension stores these URLs and periodically clears history associated with them.
- Click the Clear History button to instantly remove history for configured websites.
- The extension does not delete entire browsing history—only specified sites are affected.



**Installation**

- Download the extension’s source code.
- Go to chrome://extensions/ in Chrome.
- Enable Developer Mode (top-right toggle).
- Click Load Unpacked and select the extension folder.
- The extension is now installed! 🎉
